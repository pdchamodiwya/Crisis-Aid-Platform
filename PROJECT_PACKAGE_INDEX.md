# CrisisAid Project Package Index

The files in this folder were authored against the supplied SE205.3 coursework brief, final report structure and presentation recording guidelines. The ZIP is a substantive **code + documentation prototype package**, not a certified deployed humanitarian system.

## Start here

- `README.md`: platform modules, full setup, demo accounts (password from your own `.env`), API endpoints and limitations.
- `docs/START_HERE_WINDOWS.md`: Windows/Docker step-by-step startup.
- `Prototype_Source_Code.zip`: standalone implementation source for OneDrive sharing.
- `docs/Group_XX_Final_Report.docx` / `.pdf`: 10-chapter formatted report draft, 3,103 total words including cover/TOC/captions/tables and references; main body stays under 4,000 words.
- `docs/presentation/CrisisAid_10_Minute_Presentation.pptx`: 10-slide demo and six-member contribution template.
- `docs/Presentation_Video_Link_Submission.docx`: link hand-in template for NLearn.
- `docs/TEST_PLAN.md` and `docs/STATIC_PRECHECK_RESULTS.txt`: prepared test matrix and static checks.
- `docs/SUBMISSION_CHECKLIST.md`: required genuine evidence, upload link and sharing permissions.

## What is prepared versus incomplete

**Prepared:** Code source, responsive frontend, C# APIs, SQL models, local Docker deployment, AI-assisted human review, matching, audit, outbox, UI design, diagrams, API test collection, formatted report, 10-minute slide deck and scripted test scenarios.

**Requires actual team execution:** .NET build/xUnit, npm install/build, real browser/API/SQL testing and screenshots, Git repository with authentic member commit history, recording with cameras and member introductions, actual group details, NLearn submission and OneDrive evaluator-access URLs. The preparation environment lacked the .NET SDK and npm internet access, so no passing runtime tests are claimed.

**Deadline:** 30 November 2026.
